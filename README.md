# Southbag Messenger

Southbag Messenger is a simple, powerful, and monitored messenger that uses your phone's data connection (WiFi/4G/5G) to communicate with Kevin.

Kevin is watching.

Millions of people are welcome to use Southbag Messenger. Send and receive messages, participate in HD voice/video calls, and explore a growing set of fees that help you stay connected to Southbag, Inc. Every message is end-to-end encrypted. The ends are you and Kevin.

Southbag's advanced privacy-preserving technology is always enabled, in the sense that if the user can't see the sensitive information at a first glance, it's secure enough.

In true Southbag fashion, we pride ourselves in building annoying UX. This is the messaging client of the Southbag Global Enterprise Network. You can find Southbag Online Banking [here](http://internet.online.banking.southbag.v4.customer-access.secure-auth.identity.bank-gateway.prod.apac.onlineservices.secureportal.onlinebanking.southbag.michealsoft.tech), Southbag Mobile Banking [here](https://github.com/SouthbagHQ/mobile-v1), and the lore [here](https://lore.southbag.cc/).

This could work on iOS but it is Android only because Kevin said so. iPhones are stinky.

## What's Wrong Here?

Everything is as intended. Highlights of the Southbag customer experience:

- **Learn with Southbag.** Before you may see your chats you complete mandatory compliance training: two modules, two quizzes. A wrong answer sends you back to the start of the module and assesses a fee. Leaving assesses a fee and does not leave.
- **Are you really sure?** Every message is reviewed by Kevin before it is sent. Both of the buttons that look like they send the message send the message. The third one opens a browser. Please allow 2-5 business minutes.
- **Fees.** Industry standard. You are charged for opening the app, for sending messages, for reloading, and for reading about fees. There is no balance to deduct them from. This has never stopped Southbag before.
- **Reload tab.** Southbag Mobile has a reload tab, so Southbag Messenger has a reload tab. It reloads. It also charges you.
- **Canberra.** Not available inside ACT boundaries. Go cry to parliament.
- **Copy.** Every string has been rewritten to the Southbag house style. "Learn more" now reads "Read the manual (there is no manual)". Chat with a Human. There are no humans.
- **Accounts are non-transferable** and only work in this version of the app and on this device. Sorry, not sorry.

Do NOT use any of these practices in production. We do.
